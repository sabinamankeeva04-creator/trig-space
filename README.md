# Тригонометрия ғарышы

JUZO математика курсына арналған тригонометрия ойыны: 7 планета, әрқайсысында 8 сұрақ.
Статикалық сайт: `index.html` + KaTeX (jsDelivr CDN) + JUZ40 шрифттері (`juz40.woff`, `juz40b.woff`). Құрастыру (build) қажет емес.

## Vercel-ге шығару
1. Осы папканы GitHub-та жаңа репозиторийге жүктеңіз (мысалы, `trig-space`).
2. vercel.com → **Add New… → Project** → GitHub репозиторийін таңдаңыз → **Import**.
3. Framework Preset: **Other**, Build Command: бос, Output Directory: бос → **Deploy**.
